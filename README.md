# ComputerSeekho – Student Management System
A full-stack web-based Student Management System developed to manage student admissions, training programs, placement activities, and related administrative operations.

## 🚀 Project Overview
ComputerSeekho is a full-stack application designed to streamline student management through a centralized web platform.
The project demonstrates a multi-backend architecture with both Java Spring Boot and ASP.NET Core implementations, supported by a React frontend and MySQL database.

## 🛠️ Tech Stack
### Frontend
- React
- JavaScript
- HTML5
- CSS3
- Vite

### Backend
- Java
- Spring Boot
- Spring Data JPA
- REST APIs
- ASP.NET Core
- Entity Framework Core

### Database
- MySQL

### DevOps / Tools
- Docker
- Docker Compose
- Git & GitHub

## ✨ Key Features

- Student management
- Placement management
- Training/course management
- Authentication and authorization
- RESTful APIs
- File and image upload handling
- Email integration
- Google OAuth authentication
- PDF/report generation
- MySQL database integration
- Dockerized application setup
